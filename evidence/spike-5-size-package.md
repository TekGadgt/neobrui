# Spike 5 size/package evidence

Run `pnpm measure:size` to intentionally generate `size-report.json`, then commit the report separately from implementation. Run `pnpm verify:size` for one fresh, non-mutating build compared byte-for-byte with the committed report; it does not rewrite the report. The Node size-package tests perform repeated builds and assert deterministic CSS, archive, consumer metadata, and hashes, and `pnpm verify:clean` runs both those tests and the verifier. The report separates source-entry CSS from the actual CSS emitted by Vite after installing the local `.tgz`; emitted raw bytes are identity-transfer accounting and gzip is diagnostic (`gzip -9 -n`). Provenance is a source-input manifest hash plus clean/dirty state, not a self-referential commit SHA.

The archive is local and private only. Its manifest is CSS, README, and package metadata; runtime JavaScript/assets/dependencies are asserted as zero. Consumer imports are aggregate (`@neobrui/private-spike-candidate`) and standalone Button subpath, with foundations covered by a separate built subpath page; no network/public registry resolution occurs. The production fixture route is `http://127.0.0.1:4174/consumer/` across Chromium, Firefox, and WebKit.
