# Deliberately application-owned semantics

- Fixture-local palette aliases and identity values
- Product/application content, names, logos, imagery, motifs, and page composition
- Font family selection and font loading
- Link/hover palette and divider policy
- Component-specific CTA/navigation behavior
- Editor, preview, creator, takeaway, QR, persistence, and status-announcement behavior
- Direction-specific art choices beyond the semantic token scope

These are intentionally excluded from core token identifiers and are not generated as DTCG or other interchange artifacts.
