## Use the exact local archive

The supported alpha path starts from the generated release archive, not repository internals.

```sh
pnpm release:local
mkdir my-project && cd my-project
pnpm add ../neobrui/dist/release/neobrui-0.1.0-alpha.0.tgz
```

Import public CSS exports from your application entry point:

```css
@import 'neobrui/tokens';
@import 'neobrui/blocks';
```

The export graph is intentionally explicit: tokens → compositions → utilities → blocks → exceptions. Choose narrow exports when a page only needs one concern. DTCG is a build-time interchange file, not a runtime theme loader.

<Aside type="caution" title="Alpha boundary">Keep your product palette, typography, identity, and theme state in the consuming application. The archive is private and unpublished.</Aside>
