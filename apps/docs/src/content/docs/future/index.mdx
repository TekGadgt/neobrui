## GitHub Project Pages later

This site is statically buildable and accepts a project base path plus canonical URL without embedding a future owner or repository. Local equivalents:

```sh
PUBLIC_SITE_BASE=/neobrui/ PUBLIC_SITE_URL=https://tekgadgt.github.io/neobrui/ pnpm build
pnpm preview
```

The future path is a decision gate, not a promise of public support or compatibility. The reviewed Pages workflow and activation steps are documented in the repository's `docs/github-pages.md` guide.
