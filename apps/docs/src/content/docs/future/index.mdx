## GitHub Project Pages later

This site is statically buildable and accepts a project base path plus canonical URL without embedding a future owner or repository. Local equivalents:

```sh
PUBLIC_SITE_BASE=/neobrui/ PUBLIC_SITE_URL=https://example.invalid/neobrui/ pnpm build
pnpm preview
```

Before publication, an owner must decide the repository and URL, review the archive and support posture, and explicitly activate a deployment workflow. This repository intentionally contains no active deployment workflow, registry action, or publication credentials.

The future path is a decision gate, not a promise of public support or compatibility.
