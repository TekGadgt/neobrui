## Contract

`foundations.css` only defines custom properties on `:root`; it does not reset elements. Set variables on a product/theme ancestor or an individual instance. The values below are the source-of-truth fallbacks.

## Why system colors are intentional

`Canvas`, `CanvasText`, `ButtonFace`, `ButtonText`, `GrayText`, and `Highlight` are browser/system colors. They provide a runnable neutral layer that can adapt to user agents and forced-colors modes. They are not a product palette and do not guarantee contrast for arbitrary product overrides: verify semantic foreground/background pairs.

## Theme maps

Neutral fallback map:

```css
:root { color-scheme: light dark; /* retain the source defaults */ }
```

A distinct product map keeps the same roles but changes identity:

```css
[data-product="coral-ledger"] {
  --nbr-color-canvas: #fff8ee;
  --nbr-color-surface: #fff8ee;
  --nbr-color-surface-raised: #ffe4d3;
  --nbr-color-text: #201814;
  --nbr-color-text-muted: #765f52;
  --nbr-color-border: #201814;
  --nbr-color-focus: #005fcc;
  --nbr-color-action: #e85d3f;
  --nbr-color-on-action: #201814;
  --nbr-color-shadow: #201814;
  --nbr-radius: 0.35rem;
}
@media (prefers-color-scheme: dark) {
  [data-product="coral-ledger"] { --nbr-color-canvas: #1d1712; --nbr-color-surface: #261e18; --nbr-color-text: #fff8ee; --nbr-color-border: #f0d8bd; --nbr-color-action: #ff967c; --nbr-color-on-action: #201814; --nbr-color-shadow: #f0d8bd; }
}
```

Modern `light-dark()` can combine the map with `color-scheme`; scoped selectors are the fallback when explicit theme state is application-owned. Borders default to 2px, small shadows to 2px, raised shadows to 4px, and press translation to 2px. A quieter theme can use `1px` structural borders and `1px` offsets; a stronger theme can use at most a bounded `3px` small / `5px` raised offset. Keep shadow offsets and active translation coherent so pressed controls do not appear detached.

## Ownership and removal

Foundations owns names, neutral fallbacks, and token contracts. It does not own brand meaning, font families, element margins, reset behavior, or contrast claims. Remove the import and all consuming classes to remove the visual layer; token declarations that are otherwise unused can remain or be deleted with the product scope.
