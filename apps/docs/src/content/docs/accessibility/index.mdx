## What the automated evidence covers

Fixture automation covers Chromium, Firefox, and WebKit for native semantics, focus-visible cues, RTL and nested direction, responsive 320px layouts, reduced motion, forced-colors rules, and CSS coexistence. The docs site adds keyboard navigation and responsive shell checks.

## What remains manual

Physical keyboard and touch review, assistive technology combinations, operating-system forced-colors, and true browser UI zoom require a dated manual run. Do not infer support for markup or configurations that are not evidenced.

Keep labels, descriptions, errors, status announcements, and disabled behavior explicit in HTML and application code.
