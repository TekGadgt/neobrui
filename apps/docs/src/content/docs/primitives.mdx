## Surface

```html
<article class="nbr-surface" data-nbr-level="quiet">Quiet</article>
<article class="nbr-surface" data-nbr-level="outlined">Outlined</article>
<article class="nbr-surface" data-nbr-level="raised">Raised</article>
```

## Pressable

Apply `.nbr-pressable` to a native `<button>` or `<a>`. It coordinates hover, focus-visible, active press, reduced motion, RTL, and forced colors without claiming behavior.

```html
<button class="nbr-pressable" type="button">Save</button>
```

There is intentionally no Field or Button API in v0.
