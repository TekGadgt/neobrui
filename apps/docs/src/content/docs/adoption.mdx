## Adoption

## AI guidance

The repository-owned skill at `skills/neobrui/SKILL.md` is triggered only by explicit Neobrui or Ryan-design-language briefs. Precedence is project identity and explicit brief, then accessibility and native semantics, then Neobrui principles, then recipes.

Run static contract checks, package smoke, docs link smoke, and a representative gallery check in Chromium, Firefox, and WebKit across light/dark, narrow/wide, keyboard, axe, RTL, forced colors, and reduced motion before release claims.
