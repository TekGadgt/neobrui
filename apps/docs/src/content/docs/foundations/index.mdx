## Semantic tokens

Tokens describe roles rather than a brand palette: text, canvas, surface, focus, spacing, control geometry, and motion. Product-owned values are mapped into those roles by the consuming application.

```css
@layer nbr.tokens {
  :root {
    --nbr-color-text: #172019;
    --nbr-color-canvas: #fbfdfb;
    --nbr-color-focus: #2d5941;
  }
}
```

## Product-owned theming

Neobrui does not own a toggle or runtime state machine. Scope your theme selector, then map the same semantic roles for each mode. Nested direction and writing modes remain application concerns.

## DTCG 2025.10

`tokens.dtcg.json` is generated deterministically from the canonical token maps. It preserves themes and provenance for tooling and review; it is not a second source of truth.
