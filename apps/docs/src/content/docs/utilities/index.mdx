## Visually hidden

`.nbr-u-visually-hidden` preserves non-focusable content in the accessibility tree while removing it from visual flow. It is not `display: none`, and it does not provide a focus-reveal mode.

<div class="showcase nbr-stack">
  <p><span aria-hidden="true">●</span> <span class="nbr-u-visually-hidden">Status:</span> Draft saved.</p>
  <p><small>The hidden prefix adds context in the accessibility tree; it is not a visual hide/show gimmick.</small></p>
</div>

## Wrapper

`.nbr-u-wrapper` centers content with a readable measure and logical inline padding. Tune `--nbr-wrapper-max-inline-size` or `--nbr-wrapper-padding-inline` from your application when needed.

<div class="showcase">
  <div class="nbr-u-wrapper wrapper-demo"><strong>Visible measure boundary</strong><p>This region keeps a readable measure at wide sizes and remains padded at 320px.</p></div>
</div>

```html
<main class="nbr-u-wrapper">
  <h1>Readable by default</h1>
</main>
```
