## A useful surface, not a promise

Neobrui `0.1.0-alpha.0` is validated for controlled local use. It ships CSS and build-time DTCG interchange; it does not ship runtime JavaScript, a reset, identity, or a public support commitment.

<div class="showcase">

**The design principle:** native HTML and the consuming application own semantics, state, routing, validation, and announcements. Neobrui supplies a small, inspectable visual layer.
