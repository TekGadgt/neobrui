## Opt in, stay native

Neobrui styles only explicit classes. Native HTML owns semantics, keyboard behavior, links, validation, and state.

## Product identity wins

Core uses neutral semantic fallbacks. Products provide their own role mappings and may tune borders, shadows, and press geometry.

## Accessible by construction

Use real buttons and links, visible focus, logical properties, reduced-motion support, and forced-colors boundaries. Visual novelty never replaces meaning.
