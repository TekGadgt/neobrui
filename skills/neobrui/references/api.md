# Neobrui API reference

## Classes

- `.nbr-stack`: vertical flex flow; customize `--nbr-stack-gap`.
- `.nbr-cluster`: wrapping flex flow; customize `--nbr-cluster-gap`, alignment, and justification.
- `.nbr-wrapper`: centered inline measure.
- `.nbr-grid`: irregular 12-column grid; customize spans and gap.
- `.nbr-surface`: opt-in surface; levels are quiet, outlined, and raised.
- `.nbr-pressable`: coordinated visual states for native `<button>` and `<a>`.
- `.nbr-u-visually-hidden`: accessible visually hidden content.

All geometry and semantic color roles are custom properties. Logical inline shadow direction is the default; `data-nbr-shadow-direction="fixed"` is an explicit physical escape.
