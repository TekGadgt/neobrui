# Neobrui 0.1.0-alpha.0 release candidate

Status: release candidate prepared; not currently published or available from npm.

## Highlights

- CSS-only, reset-free, opt-in design-system surface: foundations, layout relationships, tactile primitives, utilities, and neutral semantic token hooks.
- Public CSS exports for the aggregate entry and `foundations.css`, `layout.css`, `primitives.css`, and `utilities.css`.
- Developer reference docs and the `skills/neobrui` AI guidance package are included in the package payload.
- Package rehearsal covers exact archive contents, offline script-disabled consumer installation, and readable CSS and skill files. Read-only cross-platform runner comparison tooling is included; native Ubuntu/macOS artifact comparison and trusted ARM64 candidate rehearsal remain required before tag/bootstrap.

## Installation after publication

The following is intentionally not executable until the candidate is published:

```sh
npm install @tekgadgt/neobrui@next
```

## Boundaries and support

This is the first public prerelease candidate. It has no runtime JavaScript, assets, or dependencies, and requires no framework. Native semantics, accessible names, focus behavior, application state, theming identity, and contrast sign-off remain consumer responsibilities. Manual accessibility review for keyboard/focus, 320px layouts, RTL, forced colors, reduced motion, and contrast is still required.

## Reproducibility and migration

The final archive SHA-256, SHA-512 SRI, and size are recorded by the release rehearsal after packaging; they are expected to differ from the private-preparation archive because `package.json` changed. Before upgrading from Git/local use, review the lockfile and rerun the full browser matrix. This is the first public release, so there is no prior published package migration; remove local/Git references only after the published candidate is deliberately adopted.
